# Forced Commitment Mode

The game autosaves the moment anything risky happens - raids, downed or killed pawns, mental breaks, fires and more - so no outcome can be reloaded away, and ALT+F4 cannot dodge a save. Always active in commitment mode saves; an optional setting extends the autosaves to non-commitment saves.

Every trigger is togglable; all are on by default except animal downed, animal killed, building destroyed and fire started (off to avoid frequent saves).

While a commitment save is running, all debug buttons except the log window are hidden.
